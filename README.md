## Introduction

The Aventen Formosa Sync was Aventen's first development board — a high-performance board equipped with a 600MHz RT1060 MCU (overclockable to 1GHz under the right conditions), built-in WiFi 5 + Bluetooth with audio, USB OTG, RGB LEDs, USB-C connectivity, and comprehensive battery management.

Designed for IoT makers, professionals, and industrial solutions — it offered a compact, breadboardable form factor with serious performance.

---

## Specs

| Feature | Detail |
|---|---|
| **MCU** | NXP MIMXRT106SDVL6B — ARM Cortex-M7 @ 600MHz (overclockable to 1GHz) |
| **PSRAM** | 8MB |
| **Flash** | 16MB |
| **WiFi** | WiFi 5 — Murata Type 1ZM |
| **Bluetooth** | BT 5.0 |
| **SD Card** | Built-in MicroSD slot |
| **USB** | USB-C |
| **Ethernet** | 10/100 via LAN8720A |
| **LEDs** | RGB + status LED |
| **GPIO** | 35 header pins |
| **Debug** | SWD/JTAG |
| **Power** | Battery (JST) + USB-C LiPo charging |
| **Extras** | Chip antenna + IPX U.FL · Aux LDO 1A · RF switch |

## Status

Formosa Sync reached prototype stage and confirmed first prototype. It was covered by Hackster.io and launched a Crowd Supply campaign. Development was paused in favour of the next-generation Kypros board.

## What Came Next

We built Formosa Sync. Then we asked: *what if we threw out every compromise and started over with the RT1176 — before anyone else did?*

That's **[Kypros](https://github.com/avencan/Aventen-Kypros)**.

| | Formosa Sync | Kypros |
|---|---|---|
| CPU | RT1060 @ 600MHz | **RT1176 @ 1GHz + 400MHz** |
| WiFi | WiFi 5 | **WiFi 6 (601Mbps)** |
| HDMI | ❌ | **✅ 1080p** |
| Ethernet | 10/100Mbps | **Gigabit** |
| Zigbee/Thread/Matter | ❌ | **✅ Native** |
| Audio Codec | ❌ | **✅ SGTL5000 (98dB SNR)** |
| Ultrasonic Mic | ❌ | **✅ 80kHz** |
| LiPo Native | ✅ | ✅ |
| Form Factor | Breadboardable | **69×18mm** |
